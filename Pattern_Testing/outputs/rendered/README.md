# Earlier jazz rendering examples

- [Everyday jazz](everyday_jazz.wav): initial manually selected mapping.
- [Class-mapped everyday jazz](everyday_jazz_classified.wav): later YAMNet-label
  mapping experiment.
- [Mapping report](everyday_mapping_report.json): the class-driven assignment
  report associated with the second render.

These are preserved listening examples. The original example MIDI is no longer
included in the working tree, so this folder does not provide a complete
reproduction of that experiment. The newer experiment folders include their
MIDI and mappings together.
